# Handwritten digit model

`mnist-12.onnx` is the MNIST handwritten-digit model published by the ONNX
Model Zoo and mirrored by the `onnxmodelzoo/mnist-12` Hugging Face repository.

- Source: https://huggingface.co/onnxmodelzoo/mnist-12
- Model: https://huggingface.co/onnxmodelzoo/mnist-12/blob/main/mnist-12.onnx
- SHA-256: `5c688690f8bacf667d4c2074af5ad0646ca328d7ab03eccf944a65b320171bdd`
- Upstream repository license: Apache License 2.0

The application runs this model locally through OpenCV DNN. No scan image is
sent outside the company PC.
